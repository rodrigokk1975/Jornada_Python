# 🐍 Projetos Python: Hashtag Treinamentos

Repositório com os projetos desenvolvidos durante o curso "Jornada Python" da "Hashtag Programaçao".

## 📂 Projetos

| Projeto | Descrição | Tecnologias |
|---|---|---|
| [🤖 Automação de Cadastro de Produtos](./01-automacao-cadastro-produtos) | Automatiza o login em um sistema web e o cadastro em massa de produtos a partir de um CSV | Python, PyAutoGUI, Pandas |
| [📊 Análise de Cancelamento de Clientes](./02-analise-cancelamento-clientes) | Identifica os motivos de cancelamento e simula ações que reduzem a taxa de 56,8% para 18,4% | Python, Pandas, Plotly, Jupyter |
| [💬 ChatBot com IA](./03-chatbot-ia-streamlit) | Chatbot com memória de conversa, integrado ao modelo Gemini | Python, Streamlit, Gemini API |
| [🛒 Sistema de Vendas](./04-sistema-vendas-streamlit) | Sistema para cadastrar vendas com dashboard de faturamento por vendedor e produto | Python, Streamlit, Pandas, Plotly |

## ⚙️ Como usar

Cada projeto tem seu próprio README com instruções detalhadas. De forma geral:

```bash
git clone https://github.com/rodrigokk1975/projetos-python-hashtag.git
cd Jornada_Python/nome-da-pasta-do-projeto
```

> ⚠️ Execute os scripts **de dentro da pasta de cada projeto**, pois eles usam caminhos relativos para ler arquivos como `produtos.csv` e `cancelamentos.csv`.
